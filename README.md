# ToolCommon Distribution

This public repository contains approved, immutable ZIP releases for ToolCommon application-local components.

**Public content:** Updater, Icons, Theme and WindowStyle parts that have passed explicit allowlist and SHA-256 audit.

The ToolCommon development repository and Git history remain private. Component ZIPs may contain Python source and can be read by anyone.

Updates are never installed into an application without its own integrity checks. Private components require a separately authenticated distribution service.
